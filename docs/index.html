⚠️ First-launch notes

🪟
Windows SmartScreen warning: Because this build is unsigned, Windows shows "Windows protected your PC". Click More info → Run anyway. This only appears once per machine.
🍎
macOS Gatekeeper warning: Right-click the app → Open → Open. Or run: xattr -cr /Applications/Electron\ Todo.app — then launch normally. One-time only.
🐧
Linux AppImage: Make executable first: chmod +x Electron-Todo-*.AppImage then run it. If you see a FUSE error: sudo apt install libfuse2
